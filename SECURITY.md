# Security policy

Blue Runner is proprietary Windows software. Its public repository distributes installers and approved documentation, not application source.

## Report a vulnerability privately

Use GitHub Private Vulnerability Reporting in [bluexone116/BlueRunner](https://github.com/bluexone116/BlueRunner/security/advisories/new): open **Security → Report a vulnerability**. Do not put exploit details, local configuration, credentials, personal paths, or sensitive logs in a public issue.

Include the Blue Runner version, Windows version, affected operation, expected and observed behavior, and minimal reproduction steps. Redact personal information. Do not send passwords or access tokens. If the reporting button is unavailable, wait for the repository owner to enable private reporting; no alternative private contact is designated here.

Security fixes are evaluated against the current distributed release. No support lifetime or response-time guarantee is stated. Keep the installer and its SHA-256 file together when verifying a download; a checksum detects corruption but is not a publisher signature.

See [Security and privacy](docs/security-and-privacy.md) for privileges, network access, local data, and maintenance behavior.
